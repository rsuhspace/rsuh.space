# [rsuh.space](https://rsuh.space) — Расписание РГГУ

Веб-приложение для просмотра расписания пар РГГУ. Хочется верить, что лучше официального.

## Особенности

- Два режима отображения расписания
- Дизайн, на который не больно смотреть (надеюсь)
- Читабельные формы обучения вместо криптографических челленджей
- Больше информации о парах
- Оффлайн-режим (PWA) без установки приложения из стора
- Экспорт расписания в календарь
- Кнопка "дать денег"

## Разработка

### Фронтенд

Рзухспейс написан на Vue 3. Чтобы запустить его локально, добавьте переменные среды (например, в файле `.env.local` в
корне проекта):

```dotenv
VITE_API_URL=...
```

Затем установите зависимости и запустите дев-сервер:

```bash
npm install # or yarn, pnpm, etc.
npm run dev
```

Сборка:

```bash
npm install
npm run build
```

### Бэкенд

Бэкенд умеет всего две вещи: проксировать запросы к официальному API расписания и генерировать ICS для
экспорта в календарь. Для локальной разработки можно вытащить API из https://raspis.rggu.ru, пока они не закрыли CORS.
Даже если закроют — можно проксировать запросы через Vite.

Если интересно, как оно работает, то можно заглянуть в `api/index.js`. Оно выглядит так не от хорошей жизни, а потому
что хостится в Yandex Cloud Functions. Зато дёшево (и сервер поближе).
